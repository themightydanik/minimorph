# Galactic Fun Park

Cosmic Sprint keeps its stable arena ID but now contains Star Launch, Hammer Plaza, the genuinely divergent Turbo Lane and Bounce Garden routes, Orbit Carousel and Star Finish. Select Cosmic Sprint in full-race mode, then **Course overview** to inspect the complete in-game layout; return to the character and start normally. Training tracks, Orbit Chaos and Gravity Mayhem retain their existing scenes.

All colliders, rotating-platform carry, hammer strikes, conveyors, piston motion, bounce pads, checkpoints and finish triggers use shared deterministic simulation. Bots use legal digital movement/jump commands; easy bots choose Bounce Garden and other difficulties choose Turbo Lane. DNF progress projects onto the current checkpoint interval of the relevant route rather than comparing world Z coordinates. Finisher times and championship ordering retain the PR #12 policy.

Frontend and backend must deploy together: world revision is `tournament-v1-galactic-park-v1`, protocol version remains 2. The existing world-revision guard rejects mixed worlds. Tournament order remains Cosmic Sprint → Orbit Chaos → Gravity Mayhem. Reconnection, results, rematches and empty-final safeguards remain covered by existing tests.

The renderer uses supplied local GLBs, shared containers/textures, per-part GPU instancing, frustum culling and visibility-aware streaming with distance hysteresis. Environment loading waits for the approved character import and starts when the course is selected. Nearby required assets gate race input/start; failures are visible and never replaced by primitive fallback scenery. Pending callbacks cannot resurrect a disposed scene. The overview temporarily requests the complete arena.

Source assets are retained unchanged in the pinned release; `npm run download:cosmic-assets` restores and verifies them locally. All 23 prepared runtime GLBs are versioned, with only referenced assets packaged by Vite. [The asset audit](cosmic-sprint-assets.md) documents deterministic mesh preparation, source appearance preservation, compression and kit/mechanism splitting. The exact original character, animations, audio, VFX, lighting rig and movement physics implementation are unchanged.

Simple collision planes approximate the padded floor relief (vertical fit capped at 8, carousel at 2). A small rim/foot contact difference can remain. Hammer/carousel stationary and moving parts are split at concealed shafts; the fused bumper assembly translates as a whole, with its physical head collider and no invisible long shaft. These are documented authoring constraints rather than replacement artwork. Native device profiling, player feedback and dedicated collision meshes can refine the result after review.

[Before/after and real-engine evidence](evidence/cosmic-sprint/README.md) includes both routes, all five zones, desktop/mobile, resource counters and separately labelled native-clock performance samples. Do not interpret controlled-clock replay counters as FPS.

The verified production package contains 14 environment GLBs (142,059,692 bytes), one approved character and unchanged audio. Total built Telegram payload is 175,895,602 bytes; Minima is 175,927,767 bytes. The validated self-contained MDS archive is 161,559,981 bytes. Assets stream on demand rather than downloading this whole package before play. The complete prepared library of 23 GLBs is 235,028,564 bytes / 459,994 triangles; source masters total 15,282,430 triangles. UASTC preserves 2048px maps and full mips at the cost of substantial transfer size. CDN caching and a future measured delivery optimization remain useful; no live release URLs are used by the game.
